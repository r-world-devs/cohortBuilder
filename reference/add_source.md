# Add source to Cohort object.

When Cohort object has been created without source, the method allows to
attach it.

## Usage

``` r
add_source(x, source)
```

## Arguments

- x:

  Cohort object.

- source:

  Source object to be attached.

## Value

The \`Cohort\` class object with \`Source\` attached to it.

# Show attrition plot.

Show attrition plot.

## Usage

``` r
attrition(x, ..., percent = FALSE)
```

## Arguments

- x:

  Cohort object.

- ...:

  Source specific parameters required to generate attrition.

- percent:

  Should attrition changes be presented with percentage values.

## Value

Plot object of class \`ggplot\`.

# Create a tool for setting filter values

Returns a
[`cb_tool`](https://r-world-devs.github.io/cohortBuilder/reference/cb_tool.md)
that updates filter parameter values on the last step of the cohort and
triggers the data pipeline.

## Usage

``` r
cb_tool_set_filter_values(cohort)
```

## Arguments

- cohort:

  A
  [`Cohort`](https://r-world-devs.github.io/cohortBuilder/reference/Cohort.md)
  object.

## Value

A `cb_tool` object.
